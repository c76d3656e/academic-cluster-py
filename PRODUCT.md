# Product

## Register

product

## Users

Academic researchers use Academic Cluster during long literature-review sessions to turn a research question into a traceable review, inspect sources and evidence, and export a verifiable result. Operators and administrators manage users, providers, runtime policy, usage and audit records.

## Product Purpose

Academic Cluster runs a six-node literature workflow backed by PostgreSQL checkpoints. Success means that researchers can see the actual result, navigate citations to the matching references, understand node progress, inspect source and evidence records, and recover failed runs without losing history. Administrative screens must reflect backend-enforced permissions and data.

## Brand Personality

Calm, exact, scholarly. The interface should prioritize reading and verification over decoration, with clear hierarchy and restrained motion.

## Anti-references

Avoid marketing-style landing pages, empty decorative dashboards, fabricated model thought content, unexplained gray helper copy, fake tenant selectors, and UI controls for unsupported backend capabilities.

## Design Principles

1. Show the research result and its evidence before operational metadata.
2. Make every citation, source and node state inspectable without exposing private model reasoning.
3. Keep the execution trace at node level; progressively disclose only information needed for the current task.
4. Treat backend authorization and resource shape as the source of truth.
5. Preserve reading context across desktop, tablet and mobile layouts.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, readable contrast, narrow viewports, screen-reader labels, and reduced motion. Status must not rely on color alone.
